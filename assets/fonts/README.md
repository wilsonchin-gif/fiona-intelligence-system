# Fiona Card Fonts

Fiona Market Intelligence cards use fixed Noto Sans SC assets so Chinese,
English, and numeric rendering remain consistent between local development and
Railway Linux.

## Files

- `NotoSansSC-Regular.otf`
- `NotoSansSC-Bold.otf`
- `OFL-NotoSansSC.txt`

## Source

- Font project: https://github.com/notofonts/noto-cjk
- Font paths: `Sans/SubsetOTF/SC/`
- License source: https://github.com/google/fonts/tree/main/ofl/notosanssc
